Projects & Tools

GripVR
Shababeek Interaction System
A modular, production-ready VR interaction framework for Unity. Handles grabbing, throwing, two-handed interactions, UI pointers, haptics, and hand tracking — designed to replace XRI's rigid patterns with something flexible, performant, and actually pleasant to extend.
Grab & Throw Hand Tracking Haptics UI Interaction Quest & PCVR OpenXR
ReactiveVars
Reactive State for Unity
A lightweight reactive variable system for Unity. Subscribe to value changes, bind UI elements, and create clean data flows without the boilerplate. Think ScriptableObject events, but actually ergonomic — with type-safe subscriptions and automatic cleanup.
